# src/ - API Source Directory

This is the main source directory for the Fastify backend API.

## Directory Structure

```
src/
├── index.ts          # Application entry point
├── swagger.yaml      # Auto-generated OpenAPI spec
├── gen/              # Generated code (Kubb)
│   └── kubb/
│       └── zod/      # Generated Zod schemas
├── http/             # HTTP layer
│   ├── server.ts     # Fastify server configuration
│   ├── types.ts      # TypeScript types for Fastify
│   ├── @types/       # Type definitions
│   ├── middlewares/  # Middleware functions
│   └── routes/       # Route handlers
└── ...
```

## Key Files

### index.ts
Application entry point that:
1. Loads environment variables
2. Creates Fastify server
3. Starts listening on port 4000 (override via PORT env var; legacy default is 3344)

### swagger.yaml
Auto-generated OpenAPI specification:
- Generated from route schemas
- Used by Kubb for code generation
- Available at `/docs/json`

## HTTP Layer Structure

See `http/CLAUDE.md` for detailed HTTP layer documentation.

## Generated Code (gen/kubb/)

**DO NOT EDIT** - This directory is auto-generated by Kubb:

```bash
npm run kubb  # Regenerates all generated code
```

Generates:
- Zod schemas in `src/gen/kubb/zod/`
- TypeScript types in `packages/types/kubb/`
- React Query hooks in `apps/web/src/kubb/hooks/`

## Code Generation Workflow

1. Define routes with Zod schemas
2. Routes automatically appear in Swagger
3. Run `npm run kubb` to generate:
   - Type-safe API types
   - React Query hooks for frontend
   - Zod validation schemas

## Environment Variables

Validated via `@repo/infra/env`:
- `DATABASE_URL` - PostgreSQL connection
- `BETTER_AUTH_SECRET` - Auth secret key
- `BETTER_AUTH_URL` - Auth base URL
- `RESEND_API_KEY` - Email service key

## Development Workflow

### Adding New Features
1. Create route in `http/routes/v1/{module}/`
2. Define request/response Zod schemas
3. Register route in module index
4. Run `npm run kubb` to generate types
5. Use generated React Query hooks in frontend

### Testing Routes
- Use Swagger UI at http://localhost:4000/docs
- Or use curl/Postman with the API directly

## TypeScript Configuration

The API uses strict TypeScript:
- Fastify with type providers
- Zod for runtime validation
- Full type inference from Zod schemas

## Port Configuration

Default port: **4000** (set via `PORT` in the repo root `.env`; legacy default in `env.ts` is 3344)

Configure in `src/index.ts` or via environment variable.

## Important Notes

- Never edit files in `gen/` - they're auto-generated
- Always define Zod schemas for routes (enables code gen)
- Run `npm run kubb` after route changes
- Use `FastifyTypedInstance` type for route files
- Tag routes for Swagger organization
