# CLAUDE.md - TACO-IDE API Backend Guide

## Project Overview

This is the **backend API** for TACO-IDE, built with Fastify. It provides REST endpoints for the web frontend and handles authentication via Better Auth.

## Tech Stack

- **Framework**: Fastify 5 with TypeScript
- **Validation**: Zod with fastify-type-provider-zod
- **Documentation**: Swagger/OpenAPI (auto-generated)
- **Authentication**: Better Auth (via `@repo/infra`)
- **Database**: PostgreSQL with Drizzle ORM (via `@repo/infra`)
- **Code Generation**: Kubb for TypeScript types and React Query hooks

## Architecture

```
apps/api/          <- This app (Fastify backend)
apps/web/          <- Next.js frontend
packages/infra/    <- Shared infrastructure (DB, Auth)
packages/types/    <- Shared TypeScript types (generated by Kubb)
```

## Quick Start

```bash
# From monorepo root
npm install

# Start infrastructure (PostgreSQL)
cd packages/infra && npm run docker:up

# Apply database migrations
cd packages/infra && npm run db:push

# Seed the database
cd packages/infra && npm run db:seed

# Start the API server
cd apps/api && npm run dev
```

## Authentication

Authentication is handled by Better Auth. The auth routes are automatically provided:

- `POST /v1/auth/sign-up/email` - Register new user
- `POST /v1/auth/sign-in/email` - Login
- `POST /v1/auth/sign-out` - Logout
- `POST /v1/auth/request-password-reset` - Request password reset
- `POST /v1/auth/reset-password` - Reset password
- `GET /v1/auth/session` - Get current session

## Creating New Routes

### 1. Create route file

```typescript

import { z } from "zod";
import { FastifyTypedInstance } from "../../../types";
import { ResponseSchema201, ResponseSchema400 } from "../../_responses/types";

const CreateExampleBodySchema = z.object({
  name: z.string().min(2),
});

export async function createExampleRoute(app: FastifyTypedInstance) {
  app.post(
    "/create",
    {
      schema: {
        tags: ["example"],
        description: "Create a new example",
        body: CreateExampleBodySchema,
        response: {
          201: ResponseSchema201,
          400: ResponseSchema400,
        },
      },
    },

```

### 2. Register in module index

```typescript
// src/http/routes/v1/example/index.ts
import { FastifyTypedInstance } from "../../../types";
import { createExampleRoute } from "./create";

export async function exampleRoutes(app: FastifyTypedInstance) {
  await app.register(
    async (fastify) => {
      await createExampleRoute(fastify);
    },
    { prefix: "/example" }
  );
}
```

## Environment Variables

Environment variables are validated by `@repo/infra/env`. Required:

```env
BETTER_AUTH_SECRET=your-secret-key-at-least-32-characters-long
BETTER_AUTH_URL=http://localhost:3344
```
